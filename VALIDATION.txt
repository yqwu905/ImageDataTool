ImageCompare 1.0 验证记录

构建
- 本次 EXE 为 1,218,048 字节（约 1.2 MB）。
- GCC 14 / MinGW-w64 x86_64，C++17，-Os，静态链接 C++ 运行库。
- -Wall -Wextra -Werror 通过，内嵌图标、Windows 清单与版本资源。
- 导入 DLL 仅为 Windows 系统组件；不依赖 libstdc++ / libgcc / libwinpthread DLL。

已通过的自动测试
1. 自然排序（含前导零和超长数字），顺序配对、文件名匹配、缺图空位。
2. 10,000 文件名的三文件夹合并，保持自然顺序。
3. 同组归一化矩形，单步整组撤销/重做，重复路径去重、非法矩形拒绝、越界裁剪。
4. 单图及整组标记、混合标记、类别筛选和未标记筛选；撤销后新操作清除重做栈。
5. 中文及 Unicode 项目往返还原；截断、非法 UTF-8、版本错误、尾部垃圾和随机输入拒绝。
6. CSV 引号、逗号和换行转义。
7. Windows API：中文文件夹扫描和坏图片处理。
8. GDI+：两种分辨率按同一比例导出黑框，逐像素检查黑色、边界外颜色和透明图 alpha；
   非均匀半透明图像无编辑导出时逐像素一致。
9. Win32 实际鼠标消息绘制、同步撤销/重做、单图及整组标记、并排/单图切换。
10. Windows 原子项目写入、覆盖已有项目、重开后重新扫描和还原；默认类别设置写入及重载。
11. CMake Linux 核心测试构建与执行、CMake Windows x64 交叉构建。

运行环境
- Linux 上以 ASan/UBSan 检查核心测试。LSan 因环境 ptrace 限制而关闭。
- Windows 集成测试运行于 Wine 10 + Xvfb；其依赖均位于构建临时目录，不随应用分发。

尚需在真实 Windows 设备人工验收
- Windows 10/11 原生文件夹选择器、项目打开/保存对话框和批量导出完整流程。
- 125% / 150% / 200% DPI、多显示器 DPI 切换、实际大图的峰值内存与交互流畅度。
- 真实相机文件的 EXIF 方向、色彩表现、损坏/异常图片兼容性。

本记录不把兼容层测试视为原生 Windows 验收，也不提供未经测量的帧率或内存承诺。
