图片对比 / ImageCompare 1.1
Windows 10（1703+）/ Windows 11，64 位便携版

运行
直接双击 dist\ImageCompare.exe。无需安装、管理员权限或额外下载运行库。
程序不使用网络。可通过命令行传入多个文件夹或 .icmp 项目。

快速上手
1. 点击“添加文件夹”，可一次选择多个；也可把文件夹拖入窗口。
2. 点击“按顺序配对”可切换到“文件名匹配”。
   顺序模式：每个文件夹分别自然排序，图2 在图10 前，然后按索引配对。
   文件名模式：完整文件名（含扩展名）忽略大小写匹配，取各文件夹文件名的并集。
   例如 a.jpg 与 A.JPG 匹配，a.jpg 与 a.png 不匹配。缺少的图片显示空位。
   只扫描第一层，不递归子目录。左侧文件夹可滚动；右键可移动顺序或移出项目。
3. 点击图片选中面板。方向键切换对比组，Tab 切换选中图片。
   V 切换并排和单图模式，单图模式下 Tab 可在同组各版本间轮流查看。
4. R 切换黑框工具，在任意有效图片上按住左键拖动。
   黑框按相对宽高比例应用到当前对比组的所有有效图片。
   单图模式下也同步整组。不同长宽比的图片采用相对坐标，并非内容自动配准。
   支持多个矩形、反向拖动和边界裁剪；Esc 取消正在绘制的矩形。
5. Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。
   一次联动绘制/清除/整组标记作为一个操作撤销，含已切换到其他组的修改。
   切换图片后撤销历史保留；关闭项目后撤销历史不保留。
6. 默认 A、B、C、D 四种标记，支持一图多类。按字母键或右侧按钮切换标记。
   1–9 对应前九种类别。“标记整组”控制标记是否联动，默认仅标记选中图片。
   顶部“设置 +”新增类别；超过侧栏可见数量时用“全部类别…”访问。
   新增类别会写入用户本地设置，后续新项目沿用；项目也保存自己的类别。
7. 筛选菜单可显示全部组、整组未标记、有任意标记、包含指定类别的组。
   筛选以对比组为单位，便于保留其他文件夹中的参考图片。
8. Ctrl+S 保存 .icmp 项目，记录绝对文件夹路径、类别、标记、矩形和匹配方式。
   项目不嵌入图片，换电脑后需要保持原路径。文件夹暂不可用时保留编辑数据。
   刷新重新扫描磁盘；移出文件夹会保留其已有编辑，重新加入可继续使用。
   编辑结果保留在内存，关闭前会提示保存。没有后台自动保存。
9. “导出图片”可导出当前组或当前筛选下的所有组。
   选择目录后，创建独立 ImageCompare_时间戳 子目录，避免覆盖原图或已有导出。
   每个来源文件夹单独存放；输出名称为“原始完整文件名.png”，避免同名不同格式冲突。
   例如 image.jpg 导出为 image.jpg.png。结果为 PNG，黑框为不透明纯黑像素。
   导出采用操作开始时的编辑快照；期间可继续浏览或编辑，新修改需再次导出。
   同时生成 UTF-8 BOM 的 labels.csv，记录源路径、结果路径、类别、矩形数、结果。
   失败项写入 errors.txt 并在完成时报告。取消导出会保留已完成文件。

快捷键
← / →、PageUp / PageDown：上组 / 下组
Home / End：筛选列表首组 / 末组
Tab：轮流选中同组图片
V：并排 / 单图轮看
R：浏览 / 黑框工具
F：适应窗口并复位平移
滚轮：同步缩放
浏览模式左键拖动：同步平移
右键拖动 或 空格+左键拖动：任何模式下同步平移
A / B / C / D、1–9：切换类别标记
Ctrl+Z：撤销
Ctrl+Y、Ctrl+Shift+Z：重做
Ctrl+S：保存项目
Ctrl+Shift+S：项目另存为
Ctrl+O：打开项目
Ctrl+N：新建项目
F1：说明

格式、性能与边界
- PNG、JPEG、BMP、GIF、TIFF；GIF/TIFF 处理首帧。
- JPEG EXIF 方向纠正后预览、编辑和导出。旋转图片的宽高可能相对文件存储方向交换。
- 导出保持纠正方向后的原始像素尺寸，不带回源文件元数据。
- 文件夹扫描、自然排序和配对均在后台进行，完成前可继续浏览已有图片。
- 浏览模式下左键拖动，黑框模式下左键绘制；滚轮以鼠标所在位置为中心缩放。
- 当前对比组优先解码，预读前后组；快速切换时丢弃过时的等待任务。
- 缓存解码后的预览和字体、复用绘制缓冲；拖动/缩放时快速绘制，停止操作后恢复精细显示。
- 使用 Windows 自带 WIC 异步解码，预览最长边不超过 2048；文件夹较多时进一步降低预览尺寸。
- 缩放是相对于“适应窗口”的比例；大图预览有采样，最终导出使用原始尺寸。
- 位图缓存预算 192 MiB；并非整个进程内存上限。解码、导出和窗口缓冲另占内存。
- 单张图像限制 1.2 亿像素；最多 256 个文件夹、100 种标记类别。
- 本版不含 WebP/HEIC/RAW、递归目录、像素级自动配准和可移动/缩放已提交矩形。
  已提交矩形可撤销或清除后重绘。
- 原生 Win32 自绘界面，支持 DPI 缩放。预览使用 Windows 自带 WIC/GDI，导出使用 GDI+，C++ 运行库静态链接。
- 单 EXE 包含图标、清单和版本信息。项目、导出图片为用户主动保存的数据。
  默认类别设置在 %LOCALAPPDATA%\ImageCompare\settings.icmp。

源码构建
推荐：Visual Studio 2022 Build Tools，安装“使用 C++ 的桌面开发”和 CMake。
在 PowerShell 执行：powershell -ExecutionPolicy Bypass -File .\build-windows.ps1
脚本默认编译 MinSizeRel（静态运行库）、运行测试并复制 EXE 到 dist。编译依赖仅开发机需要。
需要 ZIP、源码包和 SHA256 校验时，在 PowerShell 执行 ./build-windows.ps1 -Package。

也支持 64 位 MinGW-w64：确保 g++ / windres 在 PATH，执行 build-mingw.cmd。
跨平台核心逻辑可用 g++ -std=c++17 -O2 tests/core_tests.cpp -o core_tests 编译验证。
CMake 的 BUILD_TESTING=ON 启用核心及 Windows/GDI+ 交互测试。
